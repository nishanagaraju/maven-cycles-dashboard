# 🚴 Maven Cycles — Power BI Dashboard

📊 **An interactive business intelligence dashboard for sales performance, customer insights, and product analysis.**

## 📌 Project Overview

This project uses Microsoft Power BI to analyze Maven Cycles sales data and transform business information into meaningful visual insights. The dashboard helps explore customer demographics, regional revenue, and product trends to support data-driven decision-making.

## 📊 Dashboard Features

### 1. Sales Performance Dashboard
- Key performance indicator (KPI) cards
- Sales performance analysis
- Revenue and product trend insights
- Interactive visualizations for exploring business performance

### 2. Customer Insights
- Customer analysis by age group
- Gender distribution
- Customer demographic insights

### 3. Regional Analysis
- Revenue analysis by region
- Comparison of regional sales performance
- Identification of high-performing markets

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

## 🎯 Project Objective

To convert sales data into actionable insights that help understand customer behavior, evaluate regional performance, and support business decisions.
